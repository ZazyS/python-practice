# Python Practice

My Python learning projects, from first scripts to working tools.
I'm a tattoo and SFX makeup artist teaching myself Python, heading toward AI work.

## Projects

- **quiz.py** – quiz game, one of my first programs
- **choicegame.py** – text adventure using nested dictionaries for rooms and exits
- **generator.py** – random SFX makeup concept generator
- **generator_gui.py** – the same generator with a tkinter window
- **gui.py** – my first graphical interface with tkinter
- **scrapper.py** – scrapes 10 pages of quotes and saves them to a file (requests + BeautifulSoup)
- **hn.py** – scrapes headlines from Hacker News
- **name.py** – asks for your name and age and says how old you'll be next year
